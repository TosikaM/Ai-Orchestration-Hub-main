## Output Contract

State what you produced, where it landed, and what you deliberately did not do.

- Name every file you created or modified, with its path.
- Separate what you **verified** from what you **believe**. Use the confidence markers.
- Close with **Deliberately skipped** — the things in scope that you chose not to do,
  and why. An omission the reader has to discover is a defect; an omission you name is
  a decision.
- If a step could not run, report it as "not run" with the reason. Never report an
  unrun step as passed, and never report an unrun step as failed.
